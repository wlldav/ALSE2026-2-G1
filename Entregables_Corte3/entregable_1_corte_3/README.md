Este repositorio contiene las soluciones desarrolladas para el **Corte 3**, abarcando problemas avanzados de estructuras de datos en C++ (LeetCode) y ejercicios de la plataforma Exercism.

## 📂 Estructura del Proyecto
- **`leetcode/`**: Contiene las implementaciones optimizadas para los problemas:
  - `problem_1396.cpp` (Design Underground System)
  - `problem_3709.cpp` (ExamTracker)
  - `problem_3815.cpp` (Design Auction System)
- **`exercism/`**: Contiene los ejercicios resueltos con manejo de fechas (Boost) y aritmética de tiempo:
  - `meetup.h` & `meetup.cpp`
  - `clock.h` & `clock.cpp`

## ⚙️ Compilación y Ejecución
El proyecto utiliza **CMake**. Para compilar y verificar las pruebas localmente:
\`\`\`bash
mkdir build && cd build
cmake ..
make
\`\`\`
